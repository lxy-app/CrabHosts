启动与窗口

                

                  
登录时启动 CrabHosts登录 macOS 后自动启动 CrabHosts，无需手动打开主窗口。

                  
显示菜单栏图标通过 Tray 快速切换编辑 Profile、打开主窗口或进入设置。

                  
关闭主窗口时隐藏到菜单栏不会退出应用，也不会自动应用当前 Profile。

                

                
Profile 与系统写入

                
Tray 是导航入口，不是免确认写入通道。
在 Tray 中选择 Profile 只会切换编辑对象；点击“应用”会打开主窗口确认层，并在写入前生成新的差异预览与备份计划。

              


              

                
界面

                

                  
界面密度紧凑模式减少记录行高和区间距，适合较小屏幕。

                  
在侧栏显示记录数隐藏后仍可在 Profile 标题和 Tray 中查看记录数量。

                  
减少动态效果关闭弹层、Toast 和滚动过渡，与系统辅助功能偏好保持一致。

                

                
继续采用低饱和的暖黑 + 乳白主题。本轮不引入高饱和蓝色，也不增加另一套未经评审的主题。

              


              

                
系统写入保护

                

                  
应用前明确确认所有系统 hosts 写入都需要在主窗口确认；此保护不可关闭。
始终开启

                  
写入前自动备份仅替换 CrabHosts 托管区块，保留非托管内容；此保护不可关闭。
始终开启

                  
保留备份数量达到上限后优先清理最旧的自动备份，不影响手动导出的文件。

                

                
备份位置

                
~/Library/Application Support/CrabHosts/Backups原型仅展示路径，不会访问真实文件系统。
