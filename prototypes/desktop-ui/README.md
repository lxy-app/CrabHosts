# CrabHosts 桌面端 UI 高保真原型

这是针对现有桌面端界面的**独立设计评审原型**，不是已经完成的 Slint 实装。直接用浏览器打开 [index.html](index.html) 即可查看，无需安装依赖或启动服务。

## 设计方向

采用「暖黑 + 乳白」的中性色方案，去掉高饱和蓝色：

| 用途 | 色值 | 设计说明 |
| --- | --- | --- |
| 主窗口背景 | `#111210` | 带少量暖色，避免纯黑的生硬感 |
| 侧栏背景 | `#171815` | 与主区形成轻微层级差 |
| 卡片背景 | `#1B1C19` | 保持低对比、弱边框 |
| 主按钮 / 关键选中标记 | `#E9E6DC` | 乳白底配深色文字，代替亮蓝 |
| Profile 选中态 | `#2B2C27` | 灰白文字与细边框，不使用彩色铺底 |
| 主文字 | `#F0EEE7` | 暖白，保证按钮与内容可读性 |
| 次级文字 | `#97988F` | 用于辅助说明，不承载关键操作 |
| 启用状态 | `#A8B7A1` | 仅保留低饱和灰绿作为语义提示 |
| 删除操作 | `#D2AAA3` | 仅危险操作使用低饱和红色 |

## 界面改进

- 主按钮统一为乳白底、深色字，次按钮使用灰阶描边，确保文字清晰。
- Profile 列表增加图标、记录数和当前选择标记，选中态不再依赖鲜艳色块。
- Hosts 记录补齐固定表头、等宽 IP/Hostname、状态开关和轻量删除按钮。
- 标题栏新增全局搜索（`⌘/Ctrl K`），Hosts 记录卡新增当前 Profile 搜索（`⌘/Ctrl F`）；统一支持域名连续字符与 IP 片段模糊匹配、命中高亮和无结果反馈。
- 所有删除与备份清理入口统一使用危险操作确认层；Profile 删除需输入完整名称复核。
- 添加区使用明确的字段标签，保留“多个 Hostname 以空格分隔”的原有规则。
- 差异预览与系统 hosts 改为分段切换，并明确标注只读状态。
- 差异预览默认只显示前 8 行（紧凑窗口 6 行），明确标注总行数与“仅显示前 N 行”，不再依赖内层滚动条。
- 新增差异全屏查看器：唯一滚动层、行号/自动换行/复制、`Esc` 关闭，完整方案见 [差异预览全屏方案](../../docs/desktop-diff-viewer.md)。
- 应用确认弹层集中呈现启用记录数、目标文件、托管区块与自动备份说明。
- 新增 macOS 菜单栏 Tray 图标与 340px 快速入口弹层，支持切换编辑 Profile、返回主窗口、进入设置和模拟退出。
- 新增完整设置页：通用、外观、备份与安全、关于；侧栏右下角提供 40×40px 固定入口，同时支持 Tray 与 `⌘,` 进入。
- Helper 仅以侧栏底部 30px 紧凑状态行呈现，不把安装、更新、密码或提权操作放入设置页。
- 保留现有安全边界：Profile 编辑不自动改系统 hosts；应用必须显式确认。

## Tray 产品决策

1. **导航与写入分离**：Tray 中选择 Profile 只切换当前编辑对象，不修改系统 hosts；“本机”标记表示最近一次模拟应用快照，与当前选择分开呈现。
2. **应用仍需确认**：Tray 的“应用「Profile」…”使用省略号表示还有后续步骤；点击后回到主窗口确认层，重新生成差异与备份计划，不提供免确认快速写入。
3. **未应用状态可见**：记录新增、启停、删除或导入后，主窗口状态栏、Tray 图标和对应 Profile 会显示未应用提示。
4. **窗口生命周期完整**：默认关闭窗口隐藏到菜单栏；可选择关闭时退出。Tray 可重新打开主窗口或模拟退出，退出后可从演示占位页重新启动。
5. **设置联动明确**：关闭“显示菜单栏图标”时，关闭窗口行为自动联动为“退出应用”；重新选择“隐藏到菜单栏”会自动恢复 Tray 图标。
6. **键盘与退出行为**：支持 `Esc`、点击外部关闭 Tray，方向键移动 Tray 焦点，`⌘,` 打开设置。

## 搜索功能设计

### 双入口与作用域

| 场景 | 入口与快捷键 | 搜索范围 | 结果与后续动作 |
| --- | --- | --- | --- |
| 全局搜索 | 标题栏“全局搜索”；`⌘K` / `Ctrl K` | 所有 Profile 的名称，以及全部记录的 Hostname、IP | Profile 与记录结果分组展示；打开 Profile 或定位到具体记录 |
| 当前 Profile 搜索 | Hosts 记录卡右侧搜索框；`⌘F` / `Ctrl F` | 仅当前 Profile 记录的 Hostname、IP | 即时筛选表格、显示命中数/总数、保留启停与删除操作 |

### 匹配规则与交互状态

1. **模糊匹配定义为连续子串**：不区分大小写；`api` 可命中 `api.local`，`10.20` 可命中 `10.20.0.12`。多个空格关键词按“且”组合，可分布在 IP 与 Hostname 两个字段；不做拼音、自动纠错或正则表达式解析。
2. **字段边界清晰**：记录只匹配 Hostname 和 IP，备注仅用于结果说明，不参与命中；全局搜索额外支持 Profile 名称，当前 Profile 搜索不匹配 Profile 名称。
3. **命中可解释**：匹配的连续字符使用低饱和乳白高亮；全局记录结果显示所属 Profile、IP、Hostname、启用状态和备注，当前 Profile 显示“命中数 / 总数”。
4. **定位不等于写入**：点击全局 Profile 结果只切换编辑对象；点击记录结果会进入所属 Profile、带入相同搜索词并高亮目标行。两种动作都不生成应用计划、不修改系统 hosts。
5. **空态分开表达**：Profile 本身无记录时引导添加；搜索无结果时说明关键词与匹配范围，并提供“清除搜索”，不误导用户新增重复记录。
6. **筛选上下文可控**：手动或 Tray 切换 Profile 时清除局部筛选，避免把上一 Profile 的关键词误带到新上下文；设置页往返保留当前筛选。新增记录后清除局部筛选，确保新条目立即可见。
7. **键盘与焦点完整**：全局搜索支持 `↑/↓` 选择、`Enter` 打开、`Esc`/遮罩关闭并归还焦点；局部搜索 `Esc` 先清空关键词，空关键词时退出焦点。弹窗和全屏查看器打开时不响应后台搜索快捷键。

### 布局与实装映射

- 标题栏全局入口高 32px、最大宽 340px；窗口宽度 ≤1120px 时隐藏原型标识，优先保留搜索入口。
- 当前 Profile 搜索框为 250×34px，紧凑宽度下收窄至 220px；隐藏低优先级只读提示，保留命中数量。
- 全局搜索面板宽 680px，采用顶部关键词输入、作用域说明、分组结果和底部键盘提示四层结构；结果区为唯一滚动区域。
- 实装时建议将规范化、分词、字段匹配与高亮区间计算做成 UI 无关纯函数；桌面层只维护查询词、结果选中项与定位状态，并覆盖大小写、多 Hostname、IP 片段、无结果、跨 Profile 跳转及安全边界测试。

## 删除与清理确认设计

按影响范围分级，不为低风险操作增加不必要的步骤，也不让整组配置或备份被一键误删：

| 场景 | 确认方式 | 必须看清的信息 | 确认条件 |
| --- | --- | --- | --- |
| 删除 Hosts 记录 | 一步确认 | 所属 Profile、IP、Hostname、启用状态；系统 hosts 不会立即变化 | 点击“删除记录” |
| 删除整个 Profile | 强化确认 | Profile 名称、记录数、启用数、不可撤销、系统 hosts 与备份边界；最后一个 Profile 的后续行为 | 输入完全一致的 Profile 名称后，“删除 Profile”才可用 |
| 降低备份保留上限 | 一步确认 | 调整前后份数、超上限旧自动备份永久清理、手动导出不受影响 | 点击“确认调整”；后续按既定规则清理不重复弹窗 |
| 恢复默认偏好导致备份上限降低 | 合并确认 | 偏好重置范围，以及从当前上限降到 20 份所产生的备份清理后果 | 点击“确认恢复并调整”；未降低上限时沿用普通重置确认 |

### 统一交互规范

1. **对象与后果前置**：弹窗先展示要删除的对象，再用低饱和红色说明不可逆影响；避免只有一句“是否删除”。
2. **安全默认路径**：记录删除与备份清理默认聚焦“取消”；Profile 的名称输入框自动聚焦，但空值、部分名称或大小写不符时确认按钮保持禁用，按 `Enter` 也不会删除。
3. **所有取消路径等价**：取消按钮、右上角关闭、`Esc`、点击遮罩都不修改数据，并把焦点还给触发控件；弹窗打开时屏蔽后台页面快捷键。
4. **危险按钮语义明确**：按钮写明“删除记录 / 删除 Profile / 确认调整”，不提供“以后不再提示”，不使用容易误触的普通主按钮样式。
5. **结果可感知**：成功后 Toast 明确系统 hosts 与备份是否变化；记录删除会标记 Profile 有未应用修改，焦点移到下一行或添加字段，Profile 删除后焦点回到当前 Profile。

## 差异预览与全屏查看

1. **内联只做一眼预览**：面板固定 272px（紧凑窗口 232px），显示前 8 行（紧凑 6 行），底部条写明 `共 N 行 · 仅显示前 8 行`。内联不再放内层滚动条，避免与外层页面滚动争抢滚轮。
2. **两个可见入口**：面板头右侧“全屏”、面板底右侧“全屏查看”；原型另支持 `⌘⇧F`。打开后滚动从顶部开始。
3. **全屏只读**：最多 1180×860，唯一滚动容器；保留 `---/+++/@@/+/-` 前缀与 diff 行号；没有“应用/写入”按钮，不绕过主窗口确认。
4. **可控阅读**：自动换行、显示行号、复制；切换差异/系统 hosts 同步回内联 tab；`Esc`、遮罩点击或关闭按钮退出，焦点回到触发按钮。
5. **统计与截断可见**：头部显示 `共 N 行 · +A −R`，底部说明截断；系统 hosts 只显示总行数。

## 可评审交互

以下均为浏览器内的模拟行为：

- 全局搜索：Profile 名称、Hostname 与 IP 匹配，分组结果、示例关键词、键盘选择、无结果、打开 Profile 与定位记录。
- 当前 Profile 搜索：即时筛选、大小写不敏感、多关键词、命中高亮、计数、清除、无结果与快捷键聚焦。
- Profile 新建、切换、刷新反馈，以及输入完整名称后才能执行的删除确认。
- 记录添加、启停，以及包含对象信息与取消路径的删除确认。
- 差异预览 / 系统 hosts 切换，以及模拟导入。
- 差异预览头/底两个全屏入口、`⌘⇧F`、`Esc` 关闭与焦点归还。
- 全屏内滚动、自动换行、行号开关、复制反馈、差异/系统 hosts 切换。
- 侧栏“查看系统 hosts”直接进入同一全屏查看器（系统 hosts 模式）。
- 应用到本机的确认弹层与模拟结果反馈。
- Tray 开合、Profile 切换、模拟应用、打开主窗口、进入设置与退出/重启。
- 设置分类切换、开关与分段选项、备份保留数量、恢复默认偏好；降低备份上限及重置导致上限降低时均有清理确认。
- 关闭窗口隐藏到 Tray，或按偏好模拟退出；隐藏 Tray 与关闭行为自动联动。
- `Esc` 关闭弹层，弹层内键盘焦点循环，Tray 方向键导航，`⌘,` 打开设置，减少动态效果偏好适配。

## 事实边界

- 差异预览与全屏查看已按本原型实装到 `apps/desktop`，规范与验证记录见 [差异预览全屏方案](../../docs/desktop-diff-viewer.md)。
- 所有 Profile、记录、路径内容和状态均为模拟数据。
- 全局搜索、局部筛选与结果定位只改变本页面临时展示状态，不读取真实配置，不连接后端，也不触发系统 hosts 写入。
- 删除 Profile、删除记录、备份清理与偏好重置只改变本页面临时状态，不会删除真实配置或文件。
- 原型不会读取或写入真实 `/etc/hosts`，也不会调用 CrabHosts 后端、CLI 或任何系统命令。
- “确认应用”只更新原型内的模拟快照，不代表真实系统已发生变化。
- 登录启动、窗口关闭、退出/重启、Finder、备份保留和偏好重置均为浏览器内模拟；设置不会在刷新后持久保存。
- 本目录保留设计评审阶段的事实边界；真实工程中的 Tray、设置页与偏好持久化实装位于 `apps/desktop`，其验证结果以工程测试和原生验收记录为准。
