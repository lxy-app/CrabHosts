# CrabHosts 桌面端 UI 高保真原型

这是针对现有桌面端界面的**独立设计评审原型**，不是已经完成的 Slint 实装。直接用浏览器打开 [index.html](index.html) 即可查看，无需安装依赖或启动服务。

## 设计方向

采用「暖黑 + 乳白」的中性色方案，去掉高饱和蓝色：

| 用途 | 色值 | 设计说明 |
| --- | --- | --- |
| 主窗口背景 | `#111210` | 带少量暖色，避免纯黑的生硬感 |
| 侧栏背景 | `#171815` | 与主区形成轻微层级差 |
| 卡片背景 | `#1B1C19` | 保持低对比、弱边框 |
| 主按钮 / 关键选中标记 | `#E9E6DC` | 乳白底配深色文字，代替亮蓝 |
| Profile 选中态 | `#2B2C27` | 灰白文字与细边框，不使用彩色铺底 |
| 主文字 | `#F0EEE7` | 暖白，保证按钮与内容可读性 |
| 次级文字 | `#97988F` | 用于辅助说明，不承载关键操作 |
| 启用状态 | `#A8B7A1` | 仅保留低饱和灰绿作为语义提示 |
| 删除操作 | `#D2AAA3` | 仅危险操作使用低饱和红色 |

## 界面改进

- 主按钮统一为乳白底、深色字，次按钮使用灰阶描边，确保文字清晰。
- Profile 列表增加图标、记录数和当前选择标记，选中态不再依赖鲜艳色块。
- Hosts 记录补齐固定表头、等宽 IP/Hostname、状态开关和轻量删除按钮。
- 添加区使用明确的字段标签，保留“多个 Hostname 以空格分隔”的原有规则。
- 差异预览与系统 hosts 改为分段切换，并明确标注只读状态。
- 应用确认弹层集中呈现启用记录数、目标文件、托管区块与自动备份说明。
- 新增 macOS 菜单栏 Tray 图标与 340px 快速入口弹层，支持切换编辑 Profile、返回主窗口、进入设置和模拟退出。
- 新增完整设置页：通用、外观、备份与安全、关于；侧栏右下角提供 40×40px 固定入口，同时支持 Tray 与 `⌘,` 进入。
- Helper 仅以侧栏底部 30px 紧凑状态行呈现，不把安装、更新、密码或提权操作放入设置页。
- 保留现有安全边界：Profile 编辑不自动改系统 hosts；应用必须显式确认。

## Tray 产品决策

1. **导航与写入分离**：Tray 中选择 Profile 只切换当前编辑对象，不修改系统 hosts；“本机”标记表示最近一次模拟应用快照，与当前选择分开呈现。
2. **应用仍需确认**：Tray 的“应用「Profile」…”使用省略号表示还有后续步骤；点击后回到主窗口确认层，重新生成差异与备份计划，不提供免确认快速写入。
3. **未应用状态可见**：记录新增、启停、删除或导入后，主窗口状态栏、Tray 图标和对应 Profile 会显示未应用提示。
4. **窗口生命周期完整**：默认关闭窗口隐藏到菜单栏；可选择关闭时退出。Tray 可重新打开主窗口或模拟退出，退出后可从演示占位页重新启动。
5. **设置联动明确**：关闭“显示菜单栏图标”时，关闭窗口行为自动联动为“退出应用”；重新选择“隐藏到菜单栏”会自动恢复 Tray 图标。
6. **键盘与退出行为**：支持 `Esc`、点击外部关闭 Tray，方向键移动 Tray 焦点，`⌘,` 打开设置。

## 设置信息架构

| 分类 | 设置项 | 设计边界 |
| --- | --- | --- |
| 通用 | 登录时启动、显示菜单栏图标、关闭窗口行为 | 仅应用偏好，不自动应用 Profile |
| 外观 | 舒适/紧凑密度、侧栏记录数、减少动态效果 | 保持暖黑 + 乳白，不新增未评审主题 |
| 备份与安全 | 显式确认、自动备份、保留数量、备份位置 | 确认与备份为不可关闭的安全保护 |
| 关于 | 原型版本、安全说明、恢复默认偏好 | 重置不删除 Profile、备份或系统 hosts |

### 布局映射

- macOS 菜单栏高 30px；Tray 弹层宽 340px，顶部间距 6px、右侧间距 12px、圆角 13px。
- 设置内容最大宽度 1180px，桌面 padding 为 30px；分类导航宽 184px，与内容间距 20px。
- 设置行最小高度 76px，标题 13px、说明 12px；紧凑窗口下分类导航收窄至 154px。
- 继续沿用既有色板，主按钮和关键选中标记使用 `#E9E6DC`，未应用提示使用低饱和 `#C5A55D`。

## 可评审交互

以下均为浏览器内的模拟行为：

- Profile 新建、切换、刷新反馈与删除确认。
- 记录添加、启停与删除确认。
- 差异预览 / 系统 hosts 切换，以及模拟导入。
- 系统 hosts 只读弹层。
- 应用到本机的确认弹层与模拟结果反馈。
- Tray 开合、Profile 切换、模拟应用、打开主窗口、进入设置与退出/重启。
- 设置分类切换、开关与分段选项、备份保留数量、恢复默认偏好。
- 关闭窗口隐藏到 Tray，或按偏好模拟退出；隐藏 Tray 与关闭行为自动联动。
- `Esc` 关闭弹层，弹层内键盘焦点循环，Tray 方向键导航，`⌘,` 打开设置，减少动态效果偏好适配。

## 事实边界

- 所有 Profile、记录、路径内容和状态均为模拟数据。
- 原型不会读取或写入真实 `/etc/hosts`，也不会调用 CrabHosts 后端、CLI 或任何系统命令。
- “确认应用”只更新原型内的模拟快照，不代表真实系统已发生变化。
- 登录启动、窗口关闭、退出/重启、Finder、备份保留和偏好重置均为浏览器内模拟；设置不会在刷新后持久保存。
- 本目录保留设计评审阶段的事实边界；真实工程中的 Tray、设置页与偏好持久化实装位于 `apps/desktop`，其验证结果以工程测试和原生验收记录为准。
